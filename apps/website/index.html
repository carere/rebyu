    The screenshot in a chat. The arrow in a document. The “no, the other button.” Rebyu gives that conversation a place on the page.

    Point to the detail.

    Select an element, draw around an area, or sketch freehand. Numbered pins connect the note to its place.

    Keep the whole conversation.

    Reply, filter by page or person, and resolve the note when the detail is right. Reviews stay together across your pages.

    Make yourself at home.

    Bring your own framework. The widget carries its own UI, styles, and English and French translations.

    One plugin.
    Your website.

    Add Rebyu alongside your existing Vite plugins. Open your development server and start the conversation.

    The first npm release is being prepared. Until then, build and install from source.

    Read the configuration guide
    Install after the first npm release
    npm install -D vite-plugin-rebyu
    vite.config.ts
    import { defineConfig } from "vite";
import rebyu from "vite-plugin-rebyu";

export default defineConfig({
  plugins: [rebyu()],
});

    Development only. Rebyu is excluded from production builds.
