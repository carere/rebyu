# Triage labels

| Role / tracker label | Meaning |
| --- | --- |
| needs-triage | Maintainer evaluation needed |
| needs-info | Waiting for information |
| ready-for-agent | Fully specified for agent implementation |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |

Use these exact label strings when a skill refers to a triage role.
Readiness labels do not override blocking dependencies.
